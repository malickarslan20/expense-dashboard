Expense Tracker
A full-stack expense tracking web application built with the MERN stack (MongoDB, Express, React, Node.js) that helps users manage their personal finances with ease.


 Features:
🔐 User authentication (register/login)
➕ Add and manage income & expenses
📊 Track daily transactions
💰 Real-time balance overview (total income, expenses & net balance)
📁 Categorized transaction history

🛠️ Tech Stack
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
